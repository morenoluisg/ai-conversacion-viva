CONVERSACIÓN VIVA · SERVIDOR Y CLIENTES

Prepara la conexión de la sesión

Usa un equipo para administrar, otro para escuchar y las pantallas que necesites para proyectar.

Dirección y sesión

Introduce la dirección completa, con puerto si corresponde. Para acceso desde otro equipo, usa HTTPS. localhost siempre se refiere al equipo donde está abierto el navegador.

Usa el mismo código en administración, captura y tableros. Solo letras sin tildes, números, guiones y guiones bajos.

Abre cada función en su equipo

1. Panel completo de administración

2. Cliente de captura de audio

3. Tablero de visualización

El cliente se abrirá desde el servidor elegido. El navegador solicitará acceso al micrófono o al audio compartido cuando el operador pulse Iniciar.

Qué se configura aquí

Esta página prepara enlaces de conexión. El servicio del servidor debe estar instalado, encendido y accesible. Su dirección de escucha, los dominios permitidos y HTTPS se configuran en el despliegue.

El panel completo sigue disponible para trabajar con todo en un mismo computador. Las sesiones permanecen en memoria: descarga el cierre antes de reiniciar el servidor. Esta separación de páginas no sustituye la protección de acceso del despliegue.
